# Финские новости в Lute

Рабочая папка: `/Users/eremeev/projects/lute-v3`. Используй существующий
`scripts/extract_selkouutiset.py`; не переписывай его для обычного запуска.
Запрос новостей в этом навыке включает создание книги в Lute, если пользователь
не попросил только файлы. Дополнительное подтверждение импорта не требуется.

## Выбрать выпуск

- «Финские новости за сегодня»: вычисли сегодняшнюю дату по `Europe/Helsinki` и передай её в `--date`.
- «За вчера» или конкретная дата: вычисли нужную дату в том же часовом поясе. Если год не указан, используй текущий год, учитывая контекст разговора.
- «Последние новости»: передай `--latest`. Скрипт выбирает самый свежий выпуск из списка Yle, включая выходные радиоэфиры. Если он уже есть в Lute, сообщи об этом; не переходи к более старым выпускам.
- Если пользователь дал прямую ссылку на статью, добавь `--url`; с известной датой передавай также `--date`, чтобы проверить соответствие.

Запускай из рабочей папки:

```sh
.venv/bin/python -m scripts.extract_selkouutiset --date YYYY-MM-DD
```

или:

```sh
.venv/bin/python -m scripts.extract_selkouutiset --latest
```

Скрипт печатает заголовок и абсолютные пути к TXT и CSV. CSV уже содержит
язык `Finnish`, тег `selkouutiset` и ссылку на источник. При повторном запуске
идентичные файлы используются повторно. Не удаляй и не заменяй отличающиеся
существующие файлы; передай временную папку через `--output-dir` для нового
извлечения, сохранив предыдущие файлы.

При ошибке сообщи причину. Если сегодняшний выпуск ещё не опубликован,
не подменяй его вчерашним. Для старого выпуска вне текущего списка попроси
прямую ссылку на статью.

## Создать книгу без дубликата

Прочитай `config.yml` в рабочей папке: база находится по `DATAPATH/DBNAME`.
Для предварительных и итоговых проверок используй SQLite в режиме `mode=ro`.
Проверь, что в `languages` есть `LgName = 'Finnish'`.

Прочитай одну строку CSV через `csv.DictReader`. Проверь наличие книги этого
языка в `books` по `BkSourceURI = url` **или** `BkTitle = title`, используя
параметризованные SQL-запросы. Если книга уже есть, верни её название и ID;
не импортируй, не перезаписывай и не создавай второй экземпляр. Если найдено
несколько книг, сообщи об этом, сохранив их.

Для новой книги запусти штатный предварительный импорт без записи, передав
путь CSV из вывода экстрактора:

```sh
.venv/bin/flask --app lute.app_factory cli import_books_from_csv /absolute/path/to/file.csv
```

Убедись, что вывод сообщает ровно об одной новой книге на `Finnish` с тегом
`selkouutiset`. При пропуске или ошибке остановись. Перед записью сделай
согласованную резервную копию базы через `sqlite3.Connection.backup()`:
открой источник в режиме `mode=ro`, сохрани копию в
`DATAPATH/backups/before-selkouutiset-YYYY-MM-DD-<unique-timestamp>.db`,
не заменяя прежние резервные копии. Затем запусти:

```sh
.venv/bin/flask --app lute.app_factory cli import_books_from_csv --commit /absolute/path/to/file.csv
```

После записи заново открой базу только для чтения и проверь одну книгу
с нужным заголовком, языком и источником, наличие тега `selkouutiset`
через `booktags` и `tags2`, число страниц в `texts` и их текст в порядке
`TxOrder`. Сравни с TXT, допуская нормализацию пробелов и замену `...` на `…`
парсером Lute. При ошибке после записи сначала проверь базу, прежде чем
повторять импорт. Не добавляй книги прямыми SQL-вставками.

Отвечай кратко по-русски: созданная книга, дата и число страниц либо
«выпуск уже есть» с названием и ID. По необходимости добавь абсолютную
ссылку на TXT. Не объявляй создание успешным по результатам предварительного
импорта. Создание или изменение самого навыка не запускает импорт новостей.
