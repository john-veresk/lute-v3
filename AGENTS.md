# Правила работы в проекте

- После каждого логически завершённого изменения запускай необходимые проверки и создавай git-коммит, не дожидаясь отдельной просьбы пользователя.
- Делай отдельный коммит для каждого изменения и используй короткое сообщение, описывающее его суть.
- Включай в коммит только изменения, относящиеся к текущей задаче. Не добавляй посторонние изменения, которые уже были в рабочем дереве.
